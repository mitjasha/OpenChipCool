# План валидации микроканальной модели

Цель — сопоставление расчёта сопряжённого теплообмена с измерениями
Qu & Mudawar (2002), а затем применение проверенной методики к пластине
36 × 36 мм. Сейчас доступны входные файлы и обработка литературных данных;
расчёты OpenFOAM и экспериментальная валидация пока не выполнены.

## Источники

- Qu & Mudawar (2002), IJHMT 45, 2549–2565:
  [DOI](https://doi.org/10.1016/S0017-9310(01)00337-4),
  [авторский PDF](https://engineering.purdue.edu/mudawar/files/articles-all/2002/2002_1.pdf).
  Рис. 2–3 и табл. 1 задают геометрию; рис. 4 — перепад давления,
  рис. 5 — нагрев воды, рис. 7 — температуры меди у термопар.
- IAPWS (2011), *Revised Supplementary Release on Properties of Liquid Water
  at 0.1 MPa*: [публикация](https://iapws.org/technical-guidance/release/LiquidWater).
  Используется табличная интерполяция вязкости и теплопроводности; плотность
  и теплоёмкость постоянны. Совместимость словарей с OpenFOAM ожидает проверки.
- Celik et al. (2008): [методология GCI](https://doi.org/10.1115/1.2960953).
- OpenFOAM.com v2312: [решатели теплообмена](https://doc.openfoam.com/2312/tools/processing/solvers/rtm/heat-transfer/).

## Геометрия и границы сравнения

| Элемент | Текущая модель |
|---|---|
| 21 канал 231 × 713 мкм, шаг 467 мкм | Геометрия подготовлена |
| Длина 44.764 мм, ширина около 10 мм | Геометрия подготовлена |
| Потоки 100/200 Вт/см² | Равная полная мощность на нижней границе меди |
| Вода на входе 15 °C | Задано граничным условием |
| Поликарбонатная крышка 700 мкм | Пока заменена адиабатической стенкой |
| Три глубокие поперечные прорези и отверстия термопар | Пока отсутствуют |
| Четыре термопары | Продольные координаты заданы; положение спая и поперечные координаты требуют уточнения |
| Входной и выходной коллекторы | Пока отсутствуют |
| Температурные свойства воды | Таблицы IAPWS подготовлены |

Модель описывает ядро каналов. Полный перепад между экспериментальными
отводами давления включает сопротивления коллекторов. Температуры поверхности
канала отличаются от температур термопар внутри меди. Эти различия определяют
границы сравнения с экспериментом.

## Сопоставляемые величины

- **Рис. 4:** полный перепад — сумма потерь ядра и коллекторов. Функция
  `pressure_budget` реализует соотношения (19)–(22); поправки задаются по
  независимым площадям и скоростям. Точки, использованные для настройки
  поправки, не являются независимой выборкой для её проверки.
- **Рис. 5:** массово-взвешенная температура на выходе относительно входа.
  Энергобаланс оценивается по `Q_water = mdot Cp (T_out − T_in)`.
- **Рис. 7:** превышение температуры четырёх термопар над температурой входа.
  Координаты x: 5, 16.588, 28.176, 39.764 мм. Текущая глубина z=3.175 мм
  приближённая; уточнение геометрии входит в следующий этап.

CSV в `data/literature/` содержат приближённые ручные чтения рис. 4, 5 и 7
с условными интервалами ошибки оцифровки. Это отдельный источник погрешности
относительно приборных ошибок статьи. Повторная оцифровка высокого разрешения
и независимое чтение входят в план уточнения данных.

## Этапы численной проверки

1. Генерация сетки, разделение регионов и `checkMesh` для воды и меди;
   сохранение логов и контроль геометрии.
2. Расчёт `chtMultiRegionSimpleFoam` с записью версии, невязок, времени,
   балансов массы и энергии и полей давления/температуры.
3. Сравнение трёх сеток с удвоением разрешения по каждой координате.
   Оценка GCI применяется к монотонным последовательностям с положительным
   наблюдаемым порядком и подтверждённым асимптотическим режимом.
4. Сопоставление с литературными наблюдениями с учётом погрешности измерений
   и оцифровки. Данные настройки и независимой проверки разделяются.
5. Расширение геометрии установки и отдельная оценка влияния крышки,
   коллекторов, отверстий и прорезей на сравниваемые величины.
6. Расчёт 36-мм пластины с неоднородной тепловой нагрузкой и оценкой
   `Δp(flow)`, `h_eq(flow)`, `R_th(flow)` и их неопределённости.

Целевые показатели исследования: дисбаланс массы <0.1%, энергии <1%,
GCI целевых величин <5%, средняя абсолютная ошибка температур <5 K,
ошибка полного перепада <10%. Это пока не достигнутые цели проекта;
их применимость оценивается с учётом неопределённости исходных данных.
Эксперимент с 21 каналом не является прямой валидацией 36-мм конструкции.

## Запуск

Требуются установленный Python-проект и подключённое окружение OpenFOAM.com
v2312 с `blockMesh`, `splitMeshRegions`, `checkMesh`, `chtMultiRegionSimpleFoam`.

```bash
python scripts/build_validation_matrix.py --output cfd_cases/validation_matrix
python scripts/run_openfoam_matrix.py cfd_cases/validation_matrix/qm_q100_Re890_coarse --execute
```

После расчёта `extract_openfoam_result.py` принимает каталог кейса,
независимую поправку `--plenum-correction-pa`, файл её обоснования
`--plenum-justification` и путь экспорта `--out`. Скрипт читает
`postProcessing` и проверяет балансы. Объединённый CSV передаётся в
`validate_all_figures.py --cfd-export <combined.csv>`.

Генерация аналитических и литературных графиков не требует OpenFOAM:

```bash
python scripts/cfd_reference_report.py
python scripts/plot_figure_references.py
```

Текущая готовность компонентов — в [CFD status](cfd_status.md).
Подробная методика на английском — в [протоколе](qu_mudawar_openfoam_protocol.md).
