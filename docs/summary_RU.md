# OpenChipCool

OpenChipCool — проект моделирования жидкостного охлаждения многокристальных
корпусов. Он связывает трёхмерную тепловую модель FEM, компактную RC-сеть
и упрощённый контур охлаждения. С помощью этих моделей можно исследовать
неравномерную мощность четырёх кристаллов, изменения нагрузки и снижение
расхода теплоносителя.

## Возможности

- Стационарная и переходная теплопроводность в кремнии, TIM, эпоксидном
  заполнителе и медном основании.
- Независимые тепловые карты четырёх кристаллов с локальными горячими точками.
- Идентификация восьмиузловой RC-сети по FEM и сравнение на отдельном сценарии.
- Динамика теплоносителя и радиатора в Python и экспорт модели в Modelica.
- Интерактивные сценарии в Streamlit, графики и экспорт временных рядов.
- Генерация геометрии и входных файлов OpenFOAM для микроканальных пластин.

## Запуск

Требуется Python 3.10+. Из корня репозитория, в активированном виртуальном
окружении:

```bash
python -m pip install -e ".[dashboard,dev]"
python -m openchipcool.cli benchmark --refinement 2 --output results
streamlit run dashboard.py
```

Расчёт создаёт калибровку RC для панели. До калибровки панель использует
параметры, оценённые по геометрии. Проверки и исследование сетки:

```bash
python -m pytest -q
python -m openchipcool.cli mesh-study --refinements 1,2,3 --output results
```

Полная инструкция по установке и перечень выходных файлов — в
[README](../README.md).

## Микроканальные пластины

Литературный профиль основан на работе Qu & Mudawar (2002): 21 канал
сечением 231 × 713 мкм в медном основании. Отдельный профиль описывает
108-канальную пластину 36 × 36 мм при мощности 800 Вт, температуре воды
на входе 30 °C и расходе 4 л/мин.

Генератор создаёт три уровня сетки, словари свойств и граничные условия.
Python-проверки контролируют блочную топологию и покрытие внешних граней.
Расчёты OpenFOAM, проверка `checkMesh` и экспериментальная валидация пока
не выполнены. Графики давления и температур в `results/cfd/` содержат
аналитические оценки и приближённые чтения литературных данных.

## Границы применимости

RC-модель оценивает средние температуры кристаллов; локальные максимумы
определяются по FEM. Условия сниженного расхода выходят за пределы обучения
RC и используются для качественного анализа сценариев.

Текущая CFD-геометрия содержит ядро каналов без полного представления
коллекторов, крышки, отверстий термопар и прорезей экспериментальной установки.
Потери давления только в каналах и измеренный перепад между коллекторами
описывают разные величины. Приближённые чтения графиков имеют отдельную
погрешность оцифровки.

## Дальнейшее развитие

Следующий этап — расчёт и численная проверка подготовленных OpenFOAM-кейсов,
уточнение геометрии установки и сравнение с опубликованными измерениями.
Затем планируется получить характеристики теплоотдачи и гидравлического
сопротивления 36-мм пластины, связать их с FEM/RC и расширить контур Modelica
гидравликой насоса и трубопроводов.
